# ระบบจัดการหอพัก (RentHorPa System)

ยินดีต้อนรับสู่โปรเจกต์ **ระบบจัดการหอพัก** (RentHorPa) โปรเจกต์นี้ถูกออกแบบมาเพื่อช่วยเจ้าของหอพักในการบริหารจัดการห้องพัก, ลูกค้า, การทำสัญญาเช่า และการออกบิลค่าเช่าต่างๆ ได้อย่างมีประสิทธิภาพและง่ายดาย

## 🚀 ฟีเจอร์หลัก (Key Features)

*   **Dashboard**: ดูภาพรวมรายรับรายปี, จำนวนลูกค้า, และสถานะห้องว่างได้ในหน้าเดียว
*   **จัดการหอพัก & ห้องพัก**: เพิ่ม/ลบ/แก้ไข ข้อมูลหอพักและห้องพัก รวมถึงตั้งราคาและสถานะห้อง
*   **ระบบเช่า (Rental System)**: บันทึกการทำสัญญาเช่า, ระบุวันเข้าพัก และวันสิ้นสุดสัญญา
*   **จัดการบิล (Billing)**: สร้างบิลค่าเช่า, คำนวณค่าน้ำ-ค่าไฟอัตโนมัติ และพิมพ์ใบแจ้งหนี้เป็น PDF ได้
*   **จัดการลูกค้า**: เก็บข้อมูลผู้เช่า และดูประวัติการเช่าเช่าย้อนหลัง

---

## 🛠️ สิ่งที่ต้องมี (Prerequisites)

ก่อนเริ่มใช้งาน ตรวจสอบให้แน่ใจว่าเครื่องของคุณได้ติดตั้งโปรแกรมเหล่านี้แล้ว:

1.  **Node.js** (เวอร์ชั่น 18 หรือใหม่กว่า) - สำหรับรันแบบ Manual
2.  **Docker Desktop** - (แนะนำ) สำหรับการติดตั้งและรันแบบง่ายที่สุด

---

## 📦 วิธีการติดตั้งและใช้งาน (Installation)

### วิธีที่ 1: รันด้วย Docker (แนะนำ 🌟)
วิธีนี้ง่ายที่สุด ไม่ต้องลง Node.js หรือ Database เอง

1.  **เปิด Terminal** หรือ CMD ในโฟลเดอร์โปรเจกต์
2.  **รันคำสั่ง**:
    ```bash
    docker-compose up --build
    ```
3.  รอสักครู่จนกว่าระบบจะทำงานสำเร็จ (ขึ้นข้อความว่า Server/Database ready)
4.  **เข้าใช้งานได้ทันที**:
    *   หน้าเว็บ (Frontend): [http://localhost:5173](http://localhost:5173) (หรือ http://localhost:3000 หากรัน production build)
    *   API Backend: [http://localhost:5000](http://localhost:5000)
    *   จัดการฐานข้อมูล (PHPMyAdmin): [http://localhost:8080](http://localhost:8080)

---

### วิธีที่ 2: รันแบบ Manual (สำหรับนักพัฒนา)

หากต้องการรันเพื่อแก้ไขโค้ด:

#### 1. Setup Backend (Server)
```bash
cd backend
npm install
npm start
```
*   Server จะรันที่ `http://localhost:5000`
*   *หมายเหตุ: คุณต้องมี MySQL Database รันอยู่ และตั้งค่าในไฟล์ `.env` หรือ `src/configs/database.js` ให้ถูกต้อง*

#### 2. Setup Frontend (Client)
เปิด Terminal อีกหน้าต่างนึง:
```bash
cd client
npm install
npm run dev
```
*   เว็บจะรันที่ `http://localhost:5173`

---

## 💡 การใช้งานเบื้องต้น (Usage Guide)

1.  **เริ่มแรก**: ไปที่เมนู **"จัดการหอพัก"** เพื่อสร้างหอพักและห้องพักก่อน
2.  **ลูกค้า**: เพิ่มข้อมูลลูกค้าในเมนู **"จัดการลูกค้า"**
3.  **ทำสัญญา**: ไปที่หน้ารายละเอียดหอพัก เลือกห้องที่ "ว่าง" แล้วกด **"ทำสัญญา/เข้าอยู่"**
4.  **ออกบิล**: เมื่อถึงรอบเดือน ไปที่ **"จัดการบิล"** > **"สร้างบิลใหม่"** ระบบจะดึงค่าห้องมาให้ และให้คุณกรอกเลขมิเตอร์น้ำ/ไฟ

## ⚙️ โครงสร้างโปรเจกต์

*   `/backend` - โค้ดส่วน Server (Node.js, Express, Sequelize)
*   `/client` - โค้ดส่วนหน้าเว็บ (React, Vite, TailwindCSS)
*   `/docker-compose.yml` - ไฟล์ตั้งค่าสำหรับการจำลอง Server ด้วย Docker
